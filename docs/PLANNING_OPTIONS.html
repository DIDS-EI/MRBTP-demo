TL;DR

①结论先行

一句话

规划层（plan_behavior_trees）真正有 3 个独立可调维度：基础算法、宏动作、扩展策略；你以为的「信念方法」其实不在规划层，而是执行层（execute）的第 4 个开关。四者彼此正交、可任意组合，且都是函数级 / CLI 级参数，与具体场景解耦——所以 warehouse / smoke / home / battle 全都支持完整组合，差别只在性能，不是「某些场景不支持某种方法」。

一个常见的归类校正

常见提法实际归属说明
「要不要都扩展 / sound&complete 基础方法」规划层 ①+③「sound&complete」对应 --planner optimal（MAOBTP）；「都扩展 vs 单扩展」是另一个独立开关 --single-expand
「要不要采用信念的方法」执行层，非规划层share_belief 是 execute() 的参数，规划阶段根本不感知它
「只选一个智能体单扩展」规划层 ③就是 --single-expand，与基础算法正交
The Four Axes

②四个正交维度

每张卡是一个独立维度，可自由组合。蓝/紫/绿在规划层，橘色在执行层。

PLAN
① BASE ALGORITHM

基础算法

--planner optimal | basic

optimal = MAOBTP（默认）：代价感知，搜索前沿是优先队列（按累积动作代价 heap 排序），优先选更便宜的计划，且只有它支持宏。

basic = MABTP：FIFO 基线，纯原子动作，不支持宏。

PLAN
② MACROS

宏动作（复合子树）

--no-composite 关闭

是否预规划 LLM 式复合动作子树（如 GetKeyAndOpenDoor），被当作 0 代价单步塞进动作模型。默认开。

⚠ 仅 optimal 生效：basic 下传了会打印黄色警告并忽略。

PLAN
③ EXPANSION POLICY

扩展策略

--single-expand

全扩展（默认 False）：每弹出一个目标条件，每个 agent 都回链扩展。最大灵活性，但分支因子随队伍膨胀，多目标会爆炸。

单扩展（True）：每条件恰一个 agent 扩展，用轮转游标 rr_cursor 分工，计划期即完成分工、剪枝。

⚠ 仅 optimal 生效。

EXEC
④ BELIEF SPACE

信念空间（协同）

--no-share-belief 关闭

多智能体共享通信黑板。默认开（论文行为）：每个 agent 把预测谓词写进共享信念空间，队友据此协同、避免重复劳动。

关闭 = 协同消融实验，看团队「失去协调」。规划阶段完全不碰它。

Cost Law

⑤「每个场景都支持吗」——支持，约束只在性能

四轴全是 plan_behavior_trees / execute 的入参，与具体 Scenario 解耦，所以 4 个场景任意组合都支持。唯一现实约束是规划耗时，它遵循一条实测法则：

设计法则：每个场景给 1–2 个短跳目标即可；若确需多目标 / 多跳，优先加 --single-expand 做分工剪枝。这是「跑得快不快」的问题，不是「支不支持」的问题。
Copy-paste Recipes

⑥常用命令配方

逐维度单独触发

# ① 基础算法：FIFO 基线对照
python -m app.run --scenario home --planner basic

# ② 宏动作：关掉复合宏，回退纯原子
python -m app.run --scenario home --no-composite

# ③ 扩展策略：分工式规划（每条件一个 agent）
python -m app.run --scenario battle --single-expand

# ④ 信念空间：协同消融（执行层）
python -m app.run --scenario warehouse --no-share-belief

最硬核的全消融组合

# 分工式规划 + 关宏 + 关信念，并用 pygame 主题渲染出 GIF
python -m app.run --scenario battle \
  --planner optimal --single-expand --no-composite --no-share-belief \
  --renderer pygame --theme battle --seed 6

快速自检 / 出图

# 无头冒烟自检（带自动重试，CI 友好）
python -m app.verify

# 四房间场景出 GIF（远程无显示器友好）
python -m app.run --scenario home   --renderer pygame
python -m app.run --scenario battle --renderer pygame
记忆口诀：规划层 3 开关（算法 / 宏 / 扩展策略）+ 执行层 1 开关（信念）= 4 个正交维度；4 个场景全支持，差异只在性能不在能力。
